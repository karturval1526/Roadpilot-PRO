# RoadPilot DoorDash PRO V1

Herramienta independiente para analizar ofertas de DoorDash sin iniciar sesión en DoorDash.

## Flujo
1. El Dasher ve una oferta en DoorDash.
2. Introduce pago, millas y tiempo en RoadPilot.
3. RoadPilot calcula gasolina, mantenimiento, ganancia neta, $/milla, $/hora y Score.
4. Devuelve ACEPTAR / REVISAR / RECHAZAR.
5. El usuario puede guardar la oportunidad en el historial.

## Publicación
Subir `index.html` y `manifest.webmanifest` a GitHub Pages.

## Seguridad
No solicita usuario, contraseña, cookies ni credenciales de DoorDash.
No acepta ni rechaza órdenes automáticamente.
Los datos se almacenan localmente en el navegador.

## Nota
El Score es una herramienta de apoyo y depende de la configuración del vehículo y de la información introducida por el conductor.
